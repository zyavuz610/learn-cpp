1. INITIALIZATION (expression1) - Executed before loop starts
2. CONDITION (expression2) - Checked before each iteration
3. INCREMENT/UPDATE (expression3) - Executed after each iteration
4. LOOP BODY (statement) - Code that repeats

2. condition is checked
3. If TRUE: loop body executes
4. update executes
5. Return to step 2
*/
